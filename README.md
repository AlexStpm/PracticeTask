# Задание с практики.

Дан файл со следующей структурой
```
1563328060
КУЗНЕЦОВ АНДРЕЙ НИКОЛАЕВИЧ;21;++79465589426;MALE;Вологда, Улица мира 6;
АНАСТАСИЕВ АЛЕКСЕЙ СЕРГЕЕВИЧ;12;+79817548935;MALE;Пермь, Площадь Мужества 2;
Инна ЕвгеНЬЕВНА;62;+11321321;FEMALE;Ул Остужева;
```
Первая строка - контрольная сумма файла.
Далее идут строки со следующей структурой -

*ФИО(Строка);Возраст(Целое число);Телефон(Строка);ПОЛ(MALE или FEMALE);Адрес;*

В строке с помощью символа ";" отделены поля. Все поля обязательные
Контрольная сумма - результат работы хеш функции над содержимым файла (в примере - просто hashCode).

---------
Программа при старте должна запускает консольный интерфейс и предоставлять следующие функции:

## LOADFILE

Запрашивает имя файла на вход, загружает файл в память программы и проверить контрольную сумму. 

Пример:

```
LOADFILE
"Введите путь к файлу"
C:/test.dat
"Файл успешно загружен.
```
При загрузке файла могут произойти следующие ошибки:

1) Если совпала хеш сумма - логируется ошибка, не открывается файл. Для обработки используется исключение.
2) Формат файла поврежден - (например нет какого либо поля) - логируется ошибка, не открывается файл.  Для обработки используется исключение.
3) Не получилось прочитать файл или он не найден - логируется ошибка.  Для обработки используется исключение.
4) Повторяющееся ФИО. логируется ошибка. Для обработки НЕ используется исключение. Используется последнее найденное значение.

## SEARCH

Ищет пользователя по ФИО, не чувствительно к регистру, выводит информацию о нем. 

Пример:
```
SEARCH
"Введите ФИО"
КузНеЦов АНДРЕЙ НИКолаевич
Найден пользователь:
ФИО='КУЗНЕЦОВ АНДРЕЙ НИКОЛАЕВИЧ', ВОЗРАСТ=21, ТЕЛЕФОН='+79465589426', ПОЛ=MALE, АДРЕС='Вологда, Улица мира 6'
```
Возможные ошибки:
1) Пользователь не найден - пишется в консоль соответствующее сообщение. Логируеется ошибка.  Для обработки НЕ используется исключение.

## ADDUSER

Добавляет новую строку в данные в памяти. 

Пример:
```
ADDUSER
"Введите имя"
Богдан Вавилов
"Введите возраст"
31
"Введите телефон"
+72121112345
"Введите пол: MALE или FEMALE"
MALE
"Введите адрес"
Невский Проспект
"Пользователь создан"
```
Возможные ошибки:
1) Пользователь с таким именем уже сущесвует - логируется ошибка, пишется сообщение в консоль, пользователь не перезаписывается. Не используется исключение.
2) Неверный формат данных (например возраст < 0 или не введено поле) - логируется ошибку. Для обработки используется исключение. Поля не могут содержать символ ";"


## REMOVEUSER

Удаляет строку из данные в памяти. 

Пример:
```
REMOVEUSER
"Введите имя"
Богдан Вавилов
```
Возможные ошибки:
1) Пользователя с таким именем не сущесвует - логируется ошибка, пишется сообщение в консоль. Не используется исключение.


## SAVEFILE

Перезаписывает исходный файл, обновляет содержимое и контрольную сумму. 

Пример:
```
SAVEFILE 
"Файл успешно сохранен"
```

## SAVEFILEAS

Сохраняет файл с новым именем, обновляет содержимое и контрольную сумму. 

Пример:
```
SAVEFILEAS
"Введите путь к файлу"
C:/test23.dat
"Файл успешно загружен.
```

Возможные ошибки:
1) Не получилось прочитать файл - логируется ошибка.  Для обработки используется исключение.

## EXIT

Выход из программы.

---------
При попытке пользователя ввести несуществующую команду, например TESTUSER - генерируется исключение, обрабатывается, увеличивается счетчик неверных команд.
Если неверная команда была введена больше 3х раз - прекращается работа программы.
